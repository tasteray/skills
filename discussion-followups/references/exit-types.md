# Exit Types

Taxonomy of next-step exits, by question type. Each type has a default shape, an "honoring" rationale (why this shape fits this question), and worked examples.

The goal of typing exits is to **match the modality and register of the question**. A user asking about a song does not want a book recommendation. A user asking about a director's framing choices does not want a sibling thematic film.

---

## Type A — Scene / Song / Moment

### When it triggers

The user is asking about a specific, sensory moment: a scene, a song, a shot, a line of dialogue, a piece of staging.

**Telltale phrases:**
- "Tell me about the [X] scene"
- "What's going on with [song title] in this movie?"
- "Why does [moment] hit so hard?"
- "Break down [specific moment]"

### Why this shape

The question is at least partly **sensory**. Text alone cannot honor it. The user is asking about something they *experienced* — and the most useful next move is to let them re-experience it (the clip) or watch someone else experience it more deeply (a video essay).

The sibling scene from another film is the "if you respond to this kind of moment, here's another one" move. It's about emotional engineering, not plot.

### Default shape (3 exits)

1. **Visual companion** — the scene itself (clip) or a video essay analyzing it
2. **Sibling scene** — 1–2 films with an analogous moment, each pivoted from the current analysis
3. **(Optional) Adjacent material** — original recording, behind-the-scenes, cover version, soundtrack note

### Worked example

**Q:** "Tell me about the silent church scene in *A Quiet Place*."

**Bridge:** *"That scene works because the film makes silence functional, not aesthetic — silence is the survival mechanism, and breaking it is the violence. A few places to go with that."*

**Exits:**
- The scene itself (official Paramount clip) — worth a re-watch with attention to the sound mix
- *Every Frame a Painting: The Cinema of Silence* — broader essay on how silence is engineered in cinema
- *No Country for Old Men* (2007, gas-station coin-toss scene) — same engineering: ambient quiet weaponized as tension

### Variations

- If the moment is a **musical performance**, prefer: clip + soundtrack/cover + one sibling musical-scene
- If the moment is a **piece of dialogue**, prefer: clip + sibling-dialogue-scene + (optional) screenplay-essay
- If the moment is a **piece of staging/blocking**, prefer: clip + craft-essay + sibling-staging-scene

## Type B — Character / Theme

### When it triggers

The user is asking about character motivation, character arc, or thematic ideas in the film.

**Telltale phrases:**
- "Why does [character] do [X]?"
- "What is the film saying about [theme]?"
- "Is [character] a hero or a villain?"
- "Is this film really about [interpretation]?"

### Why this shape

The question is **conceptual**. The user is in interpretation mode. The honoring follow-up is more films that work the same conceptual territory — because thematic understanding deepens through comparison, not just through more analysis of the same film.

A video essay here is a "second mind" — an external interpreter who can push the reading further than the current conversation has room for.

### Default shape (3 exits)

1. **Sibling films** — 2–3 films with the same thematic spine, each pivoted from the current conversation
2. **Video essay** — one thematic deep dive, if a canonical one exists
3. **(Optional) Director's adjacent work** — earlier or later film by the same director that works the same theme

### Worked example

**Q:** "Why does Ben fail his own ideology in *Captain Fantastic*?"

**Bridge:** *"Ben fails because his ideology is built on control, and grief is the one variable he can't engineer around. That tension is the spine of a whole small genre."*

**Exits:**
- *The Mosquito Coast* (1986) — the canonical "father builds a utopia, family pays the price" film; almost a direct ancestor
- *Leave No Trace* (2018) — the gentler mirror: same off-grid setup, opposite emotional outcome
- *Like Stories of Old: The Limits of Ideology in Captain Fantastic* — picks up the failure-of-control reading further than we did

### Variations

- For **single-character study**, prefer: sibling-character films + a thematic essay
- For **broad thematic dives**, prefer: 3 sibling films at varying distances + 1 essay
- If the theme has a **canonical literary or philosophical source**, consider one written-text exit as the optional adjacent

## Type C — Director / Craft

### When it triggers

The user is asking about directorial choices, cinematography, editing, sound, production design, or craft more broadly.

**Telltale phrases:**
- "Why does [director] frame this scene this way?"
- "What's the cinematographer doing here?"
- "Why is this edit so jarring?"
- "How does [director] always make me feel [X]?"

### Why this shape

The question is **technical-aesthetic**. The user is treating the film as a made object. The honoring follow-up is more of the director's work (to see the choice as a *pattern*, not a one-off), an interview or commentary if one exists (to hear the choice articulated in the maker's own words), and a sibling film by a different director that uses the same technique (because contrast is teaching).

### Default shape (3 exits)

1. **Director's filmography** — 1–2 films that show this technique evolving in their work
2. **Interview / commentary** — director discussing the choice, if a canonical source exists (DGA interview, criterion essay, Director's Cut podcast)
3. **Sibling film by different director** — same technique, different sensibility

### Worked example

**Q:** "Why does Lynne Ramsay shoot *You Were Never Really Here* so fragmented?"

**Bridge:** *"That fragmentation is Ramsay's signature — she edits like memory, not like story. You can see her sharpening this across three films."*

**Exits:**
- *We Need to Talk About Kevin* (2011, Ramsay) — earlier version of the same fragmented-memory editing, applied to motherhood instead of violence
- *Morvern Callar* (2002, Ramsay) — where she first developed the lexicon
- *Bringing Out the Dead* (1999, Scorsese) — same fragmented-consciousness approach from a different sensibility; useful contrast

### Variations

- If the choice is **sound-design specific**, prefer a sound-design essay over a director interview
- If the choice is **cinematography specific**, prefer a cinematographer interview or DP commentary
- For **first-time** directors with a striking choice, prefer: their other (often short) work + a craft essay analyzing them

## Type D — Comparative

### When it triggers

The user explicitly compares this film to another, or asks how this film relates to a tradition, genre, or specific other work.

**Telltale phrases:**
- "Why does this remind me of [X]?"
- "How does this compare to [Y]?"
- "Is this basically [film] but [variation]?"
- "Where does this fit in the [tradition] of films?"

### Why this shape

The question is **relational**. The user is already in mapping mode — they're building a personal taxonomy of films and trying to place this one. The honoring follow-up is to be a *better mapper* than they are alone: one film that's even closer than their reference point (resonance), one that's the productive opposite (contrast), and optionally an essay that has done this mapping before.

### Default shape (3 exits)

1. **Film of resonance** — closer to what they're tracking than their reference point
2. **Film of contrast** — same surface, opposite philosophy
3. **(Optional) Video essay on the comparison** — if a canonical one exists

### Worked example

**Q:** "Why does *The Banshees of Inisherin* feel like a McDonagh film and also nothing like *Three Billboards*?"

**Bridge:** *"It's still McDonagh's signature — moral absurdity dressed as folk tragedy — but the volume is dialed all the way down. That distinction is the interesting one."*

**Exits:**
- *In Bruges* (2008, McDonagh) — closer in DNA to *Banshees* than *Three Billboards* is; same quiet-grief-as-comedy register
- *The Lobster* (2015, Lanthimos) — opposite philosophy with the same absurdist scaffolding: rules as cruelty instead of rules as comedy
- *Lessons from the Screenplay: McDonagh's Comedy of Despair* — does the mapping across his filmography

## Mixed and Borderline Cases

### When a question spans types

Some questions touch multiple types ("Why does Ramsay film the violence in this scene this way?" is Scene + Director). In that case:

- **Prioritize the most specific type** (Scene over Director if both apply)
- Borrow one exit from the secondary type if it strengthens the block
- Never produce 5+ exits to "cover" both types

### When the question is too thin to type

If the user just says "tell me more" or "what about this scene?" without specifying a moment, the question hasn't yet earned an exits block. Either:

- Ask one clarifying question to land on a specific moment / theme / craft choice, then produce exits
- Or treat it as a Type B (theme) by default and offer exits on the film's most central thematic spine

### When no canonical sources exist

Some scenes, songs, or films have no canonical video essay or quality clip. In that case:

- **Drop the visual companion exit entirely** — do not invent
- Compensate with one more sibling film
- The exits block can be 2 items if 3 would require fabrication
